# Goal text template

Fill every `{{…}}` and paste the result into the chapter's `## Goal` fenced block. Keep it under 4,000 characters; the chapter holds the detail. Drop a bracketed clause when it does not apply.

- `{{BASE_RULE}}` for PR 1: `from origin/main.` For a stacked PR: `from origin/<prev branch>, or from origin/main once PR <n-1> has merged; first check the base contains origin/main (git merge-base --is-ancestor) and print "PR <n> BLOCKED" if it does not.` For a PR that waits on a deploy: `from origin/main, only once PR <n-1> is deployed to staging; my first message confirms it, otherwise print "PR <n> BLOCKED: PR <n-1> not confirmed deployed".`
- `{{PAUSE_CLAUSE}}`: the pause in one sentence, with its approval file. Example: `In pr1.c2, time the 3,003-row sample exactly as the chapter says; over 15 s, commit c2 and print "PR 1 PAUSED" with the time (README §2), unless <pack>/approvals/pr1.c2 exists.`
- `{{PROOF}}`: the figure the report must carry, e.g. `the timing figure`; else drop it.
- `{{TURNS}}`: 150 unless the chapter is small (≤ 2 checkpoints: 80).
